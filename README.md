# Vexly

O Vexly é um aplicativo que conecta desenvolvedores para programarem juntos. Inspirado na dinâmica dos apps de relacionamento, você define suas preferências — como linguagem de programação, stack e nível de experiência — e o sistema encontra o parceiro ideal para o seu momento. Além do sistema de "match", o Vexly funciona como uma rede social completa, onde você pode postar seus projetos, trocar ideias e expandir seu networking com outros profissionais da tecnologia, com ou sem a intenção de codar juntos.
